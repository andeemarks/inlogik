# Product Overview

This is a message board application (mb) that appears to be a coding exercise submission. The application simulates a social media-like platform where users can:

- Post messages to projects using `@ProjectName` syntax
- Follow other users' projects
- Read messages from specific projects
- View a "wall" of messages from followed projects

The application uses a command-line interface with specific input patterns:
- `UserName -> @ProjectName message` - Post a message
- `UserName follows OtherUser` - Follow another user
- `ProjectName` - Read messages from a project
- `UserName wall` - View wall of followed projects

Built using Test-Driven Development (TDD) approach with comprehensive unit test coverage.
